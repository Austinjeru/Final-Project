# {Pork Paradise}
#### {A pork restaurant website where you can order pork and make reservations at the restaurant}, {1/5/2025}
#### By **{Austin Munene}**
## Description
{ Pork Paradise is a static, front-end web application for a pork-themed restaurant. It allows users to browse a curated menu of pork dishes, place food orders, and make table reservations directly from the website. Designed for both desktop and mobile devices, the app provides a modern and user-friendly interface with a welcoming home page, Google Maps integration for location visibility, and fully styled forms for interaction}
